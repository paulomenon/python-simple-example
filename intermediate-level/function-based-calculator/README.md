# Function-Based Calculator

A calculator where each operation is defined as a separate function. The program runs in a loop so you can perform multiple calculations without restarting.

## How to Run

```bash
python calculator.py
```

## Example

```
===== Calculator =====
1. Add
2. Subtract
3. Multiply
4. Divide
5. Power
6. Modulo
7. Quit
======================
Choose an operation (1-7): 5
Enter first number: 2
Enter second number: 10

Power: 2.0 and 10.0 = 1024.0
```

## What You'll Learn

- Defining and calling functions with parameters and return values
- Using a dictionary to map choices to functions
- Running a program in a loop with a quit option
- Basic error handling with `try/except`
