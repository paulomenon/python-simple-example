# Intermediate Level Examples

This folder contains Python examples that go beyond the basics. They introduce functions, file I/O, string manipulation, algorithms, and simple data persistence — the building blocks for real-world programs.

## Examples

| Folder | Example | Key Concepts |
|---|---|---|
| `function-based-calculator/` | Function-Based Calculator | Functions with parameters, return values, looping menus |
| `word-count-analyzer/` | Word Count Analyzer | String methods, dictionaries, sorting |
| `palindrome-checker/` | Palindrome Checker | String slicing, reversal, cleaning input |
| `fibonacci-generator/` | Fibonacci Sequence Generator | Loops, sequences, user-defined length |
| `number-base-converter/` | Number Base Converter | Binary, denary, hexadecimal, built-in conversions |
| `caesar-cipher/` | Caesar Cipher Encoder/Decoder | Character shifting, `ord()`/`chr()`, modular arithmetic |
| `file-search-tool/` | Simple File Search Tool | `os` module, directory walking, file filtering |
| `todo-list/` | To-Do List (with file saving) | File I/O, lists, persistent storage with JSON |
| `text-adventure-game/` | Basic Text Adventure Game | Functions, game state, dictionaries as data structures |
| `email-slicer/` | Email Slicer | String splitting, parsing, input validation |

## How to Run

Each subfolder is self-contained. Navigate into any folder, read its README, and run the script:

```bash
cd intermediate-level/palindrome-checker
python palindrome_checker.py
```

No external dependencies are required — all examples use the Python standard library only.

## Prerequisites

- Python 3.6 or higher
- A terminal or command prompt

## Structure

Every example follows the same pattern:

```
folder-name/
├── script_name.py    # The Python script
└── README.md         # How to run it, example output, what you'll learn
```
