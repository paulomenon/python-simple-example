# Simple Calculator

A basic calculator that takes two numbers and performs addition, subtraction, multiplication, or division based on the user's choice.

## How to Run

```bash
python simple_calculator.py
```

## Example

```
Simple Calculator
------------------------------
Enter the first number: 15
Enter the second number: 4

Choose an operation:
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)

Enter your choice (1/2/3/4): 4

15.0 / 4.0 = 3.75
```

## What You'll Learn

- Getting user input with `input()`
- Converting strings to numbers with `float()`
- Using `if/elif/else` for decision making
- Basic error handling (division by zero)
