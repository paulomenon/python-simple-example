# Beginner Level Examples

This folder contains introductory Python examples covering the fundamentals: printing, variables, input, conditionals, loops, functions, lists, and more.

## Examples

| Folder | Example | Key Concepts |
|---|---|---|
| `hello-world-sample/` | Hello World | `print()`, basic script structure |
| `welcome-sample/` | Name Input Program | `input()`, string concatenation |
| `calculator-sample/` | Simple Calculator | User input, `if/elif/else`, arithmetic |
| `even-odd-sample/` | Even or Odd Checker | Modulo operator (`%`), conditionals |
| `age-checker-sample/` | Age Checker | Chained conditionals, f-strings |
| `loop-samples/` | Loop Counters | `for` loop, `while` loop, `range()` |
| `multiplication-table-sample/` | Multiplication Table | Loops, string formatting |
| `temperature-converter-sample/` | Temperature Converter | Math formulas, float formatting |
| `constant/` | Unit Converters | Constants, functions, miles/km, cm/inches |
| `array-sample/` | Arrays and Lists | Lists, iteration, add/remove/find |
| `welcome-function/` | Functions | Defining and calling functions, return values |
| `match-choice-sample/` | Match/Case | Python 3.10+ structural pattern matching |
| `game-samples/` | Mini Games | Loops, random numbers, user interaction |
| `spreadsheet-sample/` | Spreadsheet to SQLite to PDF | File I/O, databases, PDF generation |

## How to Run

Each subfolder is self-contained. Navigate into any folder, read its README, and run the script:

```bash
cd beginner-level/hello-world-sample
python hello_world.py
```

Most examples use only the Python standard library. The `spreadsheet-sample/` requires `openpyxl` and `reportlab` — see its README for details.

## Prerequisites

- Python 3.6 or higher
- A terminal or command prompt
