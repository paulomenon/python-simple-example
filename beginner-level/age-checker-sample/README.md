# Age Checker

A program that asks for your name and age, determines your age group (child, teenager, adult, senior), and tells you what milestones you've reached.

## How to Run

```bash
python age_checker.py
```

## Example

```
Enter your name: Paulo
Enter your age: 25

Hello, Paulo! You are 25 years old.
You are an adult.
You can vote and drive.
You are old enough to drive.
You are old enough to vote.
You are old enough to drink (in the US).
```

```
Enter your name: Anna
Enter your age: 15

Hello, Anna! You are 15 years old.
You are a teenager.
You can watch PG-13 movies.
```

## What You'll Learn

- Chaining multiple `if/elif/else` conditions
- Using comparison operators (`<`, `>=`)
- Combining user input with formatted output using f-strings
