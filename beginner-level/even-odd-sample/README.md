# Even or Odd Checker

A simple program that checks whether a given number is even or odd.

## How to Run

```bash
python even_or_odd.py
```

## Example

```
Enter a number: 7
7 is Odd.
```

```
Enter a number: 12
12 is Even.
```

## What You'll Learn

- The modulo operator (`%`) to get the remainder of a division
- Using `if/else` for conditional logic
- Converting user input to an integer with `int()`
