## Installation

To set up the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/paulomenon/python-simple-example.git
   ```
2. Navigate to the project directory:
   ```bash
   cd python-simple-example
   ```
3. (Optional) Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

4. Install required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

To run the example script, execute the following command in your terminal:

```bash
python main.py
```

Make sure to replace `main.py` with the appropriate script name if it differs.
