# Multiplication Table

A program that generates a full multiplication table (1 through 12) for any number the user enters.

## How to Run

```bash
python multiplication_table.py
```

## Example

```
Enter a number to see its multiplication table: 7

Multiplication Table for 7
-------------------------
7 x  1 = 7
7 x  2 = 14
7 x  3 = 21
7 x  4 = 28
7 x  5 = 35
7 x  6 = 42
7 x  7 = 49
7 x  8 = 56
7 x  9 = 63
7 x 10 = 70
7 x 11 = 77
7 x 12 = 84
```

## What You'll Learn

- Using a `for` loop with `range()`
- String formatting with f-strings and alignment (`:2d`)
- Basic arithmetic inside a loop
